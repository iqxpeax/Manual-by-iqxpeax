## 🚀 Как открыть

Открой `index.html` в браузере — всё встроено, интернет нужен только для шрифтов.

---

## 🌙 Темы оформления

- **Тёмная** — по умолчанию (чёрно-серая палитра)
- **Светлая** — переключается кнопкой `🌙` в шапке сайта
- Выбор сохраняется в localStorage и запоминается при следующем открытии

---

## ✏️ Как редактировать

Открой `assets/js/general.js` — массив `pages[]`.

```js
{
  title: "Название раздела",
  tag: "Тег",
  intro: "Вступление",
  callout: { label: "📌 Заметка", text: "Текст" },
  calloutLink: { href: "https://...", label: "Ссылка ↗" },
  content: `HTML контент`,
  steps: ["Шаг 1", "Шаг 2"],
}
```

**Добавить картинку:**
```js
${localImg('image36.png', 'Подпись')}
```

**Добавить блок кода:**
```js
${codeBlock(`текст или команда`)}
```

## 💾 Сохранение прогресса

- Автосохранение каждые 2 минуты
- Кнопка 💾 в шапке — ручное сохранение
- При следующем открытии — возврат к последнему разделу
