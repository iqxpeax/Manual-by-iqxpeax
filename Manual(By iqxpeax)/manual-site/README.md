## 📁 Структура проекта

```
manual-site/
│
├── index.html              ← Главная страница (открывать в браузере)
│
├── assets/
│   ├── css/
│   │   ├── general.css     ← Основные стили (сайдбар, страницы, кнопки)
│   │   └── main.css        ← Доп. стили (сохранение, уведомления, футер)
│   │
│   ├── js/
│   │   ├── general.js      ← Весь контент страниц + навигация
│   │   ├── images.js       ← Все скриншоты встроены как base64 (не трогать)
│   │   └── save.js         ← Сохранение прогресса в localStorage
│   │
│   └── img/                ← Дополнительные изображения (если нужны)
│
├── errors/
│   ├── 404.html            ← Страница "не найдено"
│   └── 500.html            ← Страница "ошибка сервера"
│
├── pages/                  ← Зарезервировано для отдельных страниц
│
├── README.md               ← Этот файл
└── LICENSE                 ← Лицензия
```

---

## 🚀 Как запустить

Просто открой `index.html` в браузере — интернет не нужен, всё встроено.

---

## ✏️ Как редактировать контент

Открой `assets/js/general.js` — там массив `pages[]`.  
Каждая страница — отдельный объект:

```js
{
  title: "Название",
  tag: "Тег",
  intro: "Краткое описание вверху",
  callout: { label: "📌 Заголовок", text: "Текст заметки" },
  calloutLink: { href: "https://...", label: "Ссылка ↗" }, // необязательно
  content: `HTML контент страницы`,
  steps: ["Шаг 1", "Шаг 2", "Шаг 3"],
}
```

### Добавить изображение из документа:
```js
${localImg('image36.png', 'Подпись под фото')}
```

### Добавить блок кода с кнопкой копирования:
```js
${codeBlock(`ваш текст или поисковая строка`)}
```

---

## 💾 Сохранение прогресса

Прогресс сохраняется автоматически каждые 2 минуты в `localStorage`.  
Кнопка 💾 в шапке — ручное сохранение.  
При следующем открытии страница откроется на том же месте.
